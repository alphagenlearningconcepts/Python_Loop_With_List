Code Execution

How the Loop Tracks Index

CODE FORMULA
# Step 1: Given List
numbers = [2, 8, 16, 24]
# Step 2: Initialize sum
total_sum = 0
# Step 3: Run loop
for i in range(len(numbers)):
  total_sum = total_sum + numbers[i]
print("Total Sum =", total_sum)
💡 Why `numbers[i]`?
When i = 0, numbers[0] = 2.
When i = 1, numbers[1] = 8, and so on!
